# Ruchi Ranga food truck website

Plain HTML, CSS and JavaScript. No build step, no installation.

## Files
- index.html – page content, title and meta tags
- style.css – colours, layout and animations (colours are variables at the top)
- script.js – WhatsApp number (top of file), buttons, animations
- images/truck.webp – photo of the truck

## Preview
Open index.html in a browser. An internet connection is needed for the Google Fonts.

## Edit
- WhatsApp number: change `WA` at the top of script.js (digits with country code, e.g. 919353009622).
- Phone numbers, address, hours and reviews: edit index.html.
- New photo: put it in images/ and use it in an <img> tag in index.html.

## Publish
Upload the whole folder to any static host (Netlify, Vercel, GitHub Pages or your own hosting).
Before launch, add the domain URL and a share image to the og: meta tags in index.html.
